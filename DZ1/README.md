# ДЗ 1. Зоопарк, который живёт сам

## Этап 1. Класс Animal

- При создании животного задаём имя. Возраст и число дней без еды начинаются с нуля.
- `growOlder()` прибавляет один день к возрасту и счётчику дней без еды.
- `eat()` сбрасывает счётчик дней без еды до нуля.
- `description` собирает текущие значения в строку, а `makeSound()` возвращает звук.

Запуск из корня репозитория

```sh
swift DZ1/main.swift
```

Пример вывода

```text
Имя: Тоша, возраст: 0, дней без еды: 0
Неизвестный звук
Имя: Тоша, возраст: 1, дней без еды: 1
Имя: Тоша, возраст: 1, дней без еды: 0
```

## Этап 2. Виды животных

У базового класса `Animal` свойство `maxAge` равно 10. Наследники переопределяют `maxAge` и `makeSound()` с помощью `override`. Возраст измеряется в условных днях симуляции.

При запуске после проверки первого этапа выводятся звук и срок жизни каждого вида.

```text
Кролик: Фыр-фыр 12
Попугай: Привет! 15
Черепаха: Тишина — тоже ответ 20
Кот: Мяу 14
Собака: Гав 16
```

## Этап 3. Класс Zoo

Зоопарк хранит всех животных в одном массиве `[Animal]`. Метод `add(animal:)` добавляет животное, а `showAnimals()` выводит описание и звук каждого животного.

В примере в зоопарке десять животных, по два каждого вида. Первые две строки списка выглядят так:

```text
Имя: Пушок, возраст: 0, дней без еды: 0, звук: Фыр-фыр
Имя: Кеша, возраст: 0, дней без еды: 0, звук: Привет!
```

## Этап 4. Проверка жизни животного

Свойство `isAlive` возвращает `true`, пока возраст меньше `maxAge` и дней без еды меньше трёх.

```text
Пушинка жива после двух дней без еды: true
Пушинка жива после трёх дней без еды: false
Рыжик жив после кормления перед третьим днём: true
Шелли жива в 19 дней: true
Шелли жива в 20 дней: false
```

## Этап 5. Один день в зоопарке

`liveOneDay()` сначала сохраняет список участников дня в `todayAnimals`. Затем для каждого животного выбирает действие: 1 — кормление, 2 — отдых. После действия животное стареет. В конце дня зоопарк удаляет умерших и выводит число оставшихся.

Для ручной проверки вызываем `liveOneDay(action: 1)`. Снежинка начинает день с двумя днями без еды. После кормления счётчик сбрасывается до нуля, а после старения становится равен одному.

```text
Проверка дня с кормлением
Снежинка ест.
Осталось животных: 1
Имя: Снежинка, возраст: 3, дней без еды: 1
```

На пятом этапе цикл был рассчитан на срок до десяти дней с досрочной остановкой, если зоопарк опустел.

## Этап 6. Рождения

Действие 3 — попытка рождения. У родителя должен быть возраст от двух дней и максимум один день без еды. `makeBaby()` создаёт малыша того же вида. Родившихся храним в массиве `babies` и добавляем в зоопарк после удаления погибших.

Перед каждым рождением проверяем, что `todayAnimals.count + babies.count < 30`. Место погибшего животного можно занять со следующего дня.

В ручной проверке `liveOneDay(action: 3)` Снежинка рождает крольчонка, а Чижик ещё слишком молод. В конце дня в зоопарке три животных. Строка про новорождённого показывает, что возраст и счётчик голода равны нулю:

```text
Имя: Малыш, возраст: 0, дней без еды: 0, звук: Фыр-фыр
```

## Этап 7. Итоговая симуляция

Основной зоопарк начинает с десяти животных и работает до 30 дней без ввода пользователя. Каждый день программа печатает действия, рождения, имена погибших и число оставшихся. Если животных больше нет, цикл заканчивается.

Фрагмент одного запуска

```text
День 21
Малыш отдыхает.
Малыш погибает.
Осталось животных: 0

Итоги симуляции
Было животных: 10
Рождений: 7
Смертей: 17
Осталось животных: 0
Проверка баланса: 10 + 7 - 17 = 0
Баланс сходится: true
```

Проверены кормление, гибель на третий день без еды и при достижении `maxAge`, отсутствие рождений у незрелых животных, класс и нулевой возраст новорождённого, лимит в 30 животных и остановка при пустом зоопарке.
