# ДЗ 2. Каталог проката для космического пикника

## Этап 1. Категории и записи каталога

- `EquipmentKind` хранит три категории. Их строковые значения совпадают с названиями вариантов.
- `Equipment` хранит название, цену и категорию. Свойство `description` собирает их в одну строку.
- Три записи создаём вручную, собираем в массив `catalog` и печатаем циклом `for`.

Запуск из корня репозитория

```sh
swift DZ2/main.swift
```

Ожидаемый вывод

```text
Название: Палатка для похода, цена: 2500, категория: tent
Название: Кресло рыболовное, цена: 700, категория: chair
Название: Лампа настольная, цена: 400, категория: lamp
```

## Этап 2. Копирование записи

Создаём копию кресла через `var chairCopy = chair` и меняем её цену на 500. `Equipment` — структура, поэтому у исходной записи цена остаётся 700.

После списка каталога программа выводит обе цены.

```text
Цена исходного кресла: 700
Цена копии: 500
```

## Этап 3. Отчёт по каталогу

Цикл `for` выводит предметы с ценой меньше 1000, прибавляет цену каждого предмета к `totalPrice` и увеличивает `lampCount` для категории `.lamp`.

```text
Предметы дешевле 1000:
Название: Кресло рыболовное, цена: 700, категория: chair
Название: Лампа настольная, цена: 400, категория: lamp
Общая цена: 3600
Количество ламп: 1
```

## Этап 4. Разбор текста

Данные каталога записаны в многострочной строке `text`.

Каждую строку делим по `;`, сохраняя пустые поля. Проверяем количество полей, категорию, название и цену. При ошибке печатаем причину и переходим к следующей строке.

Программа выводит 4 корректные записи и 2 ошибки. Дешевле 1000 стоят кресло и две лампы. Сумма цен равна 3900, ламп в каталоге 2. Для примера копирования берём первую корректную запись, если каталог заполнен.

## Этап 5. Чтение файла

При запуске из корня репозитория программа читает `DZ2/equipment.txt` в UTF-8. Если файл прочитать не удалось, `catch` выводит сообщение и программа завершается. Перед разбором заменяем CRLF (`\r\n`) на LF (`\n`). Пустые строки пропускаются.

На данных из `equipment.txt` ожидаются 4 корректные записи, 2 ошибки, общая цена 3900 и 2 лампы.

Вывод для пустого файла

```text
Корректных записей: 0
Ошибочных строк: 0
Предметы дешевле 1000:
Общая цена: 0
Количество ламп: 0
```
